# SSH Key Generator GUI

A Python GUI application for automating SSH key creation.

## Setup

### System Dependencies

This application requires tkinter for the GUI. On Linux, install it as a system package:

```bash
sudo apt install python3-tk
```

### Virtual Environment

To create a virtual environment, first install the required system package:

```bash
sudo apt install python3-venv
```

Then create and activate the virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

## Running the Application

```bash
python app.py
```

## Current Features

- Single input field (base application)
